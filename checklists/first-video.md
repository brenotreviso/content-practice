# First video — 7-day path

Use with [chapter 0](../docs/00-start-here.md). If a day slips, pick up the next step; do not restart the week.

## Day 1 — One interest, one person

- [ ] I wrote one interest I already have
- [ ] I wrote one person I would like to be useful to
- [ ] I did not wait for a perfect niche

## Day 2 — A 20–40 second script

- [ ] I wrote a hook, a short body, a payoff, and an optional CTA that is not a sale
- [ ] The hook and the payoff match
- [ ] I read it out loud and it fits a length I will actually film

## Day 3 — Film on my phone

- [ ] I filmed it (hands-and-voice is allowed)
- [ ] I have enough light to see the subject
- [ ] I am not waiting for new gear

## Day 4 — Edit, captions, cover

- [ ] I cut the dead start and the dead end
- [ ] Captions (or on-screen text) match what is said, and I read them back
- [ ] The cover still matches the promise

## Day 5 — Post to one platform only

- [ ] I posted to **one** platform
- [ ] I used [before-you-post.md](before-you-post.md)
- [ ] I did not also “just quickly” post the same thing everywhere else this week

## Day 6 — Reply, don’t refresh

- [ ] I replied to genuine comments, if any
- [ ] I did not refresh the numbers all day

## Day 7 — 48-hour review

- [ ] I completed [review-48h.md](review-48h.md)
- [ ] I did **not** unpublish or delete the post because the numbers were small
- [ ] I wrote one next step

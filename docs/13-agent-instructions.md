# 13 · Agent instructions

> **In one sentence:** an AI agent using this guide should help a human plan, draft, check and review content — without inventing stats, adding monetisation, or treating Maya as a real person.

This chapter is for humans who want to know what the agent is supposed to do, and for agents that have already read [`AGENTS.md`](https://github.com/brenotreviso/content-practice/blob/main/AGENTS.md). The step-by-step skill is [`.agents/skills/content-practice/SKILL.md`](https://github.com/brenotreviso/content-practice/blob/main/.agents/skills/content-practice/SKILL.md).

## What an agent may do

- Help fill a brand sheet, pillar list, idea tree, script template, calendar, batch plan or analytics review, in the learner’s own voice.
- Suggest a container, production format and content type, with reasons from [chapter 5](05-formats.md).
- Point at official Help pages and at the [platform snapshot](platform-snapshot.md).
- Check a draft against a checklist (promise matches hook, captions, hashtag limits, no invented facts).
- If the pictures will be *coded motion*, load the [Coded Motion](https://github.com/brenotreviso/coded-motion) skill as well, and do not pretend this guide teaches GSAP.

## What an agent must not do

- Invent statistics, quotes, studies, or people.
- Treat **Maya Sen** as a real creator, client, or source.
- Add monetisation, growth-hacks, bought followers, or “guaranteed viral” advice.
- Quote Reddit as if it were a survey.
- Present disputed or unverified items (Zeigarnik as settled science, PAS inventor, AIDA origin, TikTok “Others searched for” official Help, and anything marked unverified in [sources](sources.md)) as facts.
- Publish, post, comment, email, or create a social account unless the human has clearly asked for that specific action.

## Definition of done (for a single video)

- [ ] Brand sheet and pillars exist (or the human declined them on purpose)
- [ ] One promise, one format, one script from a named framework
- [ ] Hook and payoff match; CTA is not a sale
- [ ] Caption, cover, and (if YouTube) title are honest
- [ ] Official limits checked against the snapshot (hashtags, Trial Reels, metric names)
- [ ] After posting, a 48-hour review is filled in with official numbers only
- [ ] Sources for any external claim are listed

## How this sits with Coded Motion

If the human wants animation written in code, follow Coded Motion’s `AGENTS.md` for the pictures and this guide for the idea, script, packaging, posting and review.

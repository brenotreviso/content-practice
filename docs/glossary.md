# Glossary

Short definitions used in this guide. If a chapter and this page ever disagree, prefer the chapter and then file a correction.

| Term | Plain meaning |
|---|---|
| **AIDA** | Attention, Interest, Desire, Action — an old copy sequence. Origin disputed. Desire/Action here are not “buy”. |
| **Analytics / insights** | Official numbers about how a post or account did. |
| **Autocomplete / predictions** | Phrases that appear while you type in a search box. |
| **Batching** | Doing the same kind of work in one block of time. |
| **Boundaries** | What you will not film, say or share. |
| **Brand / brand sheet** | The pattern people recognise, written on one page. |
| **Call to action (CTA)** | A next step you offer. In this guide, never a sale. |
| **Candidate generation** | The first step of many recommenders: gather a pool of posts. |
| **Caption** | The written text that sits with a post. |
| **Captions / subtitles** | Words on or under the video that follow the speech. |
| **Carousel** | Several stills a viewer swipes through. |
| **Click-through rate (CTR)** | Of the people who saw a thumbnail (impressions), the share who clicked. |
| **Cognitive load** | How much mental capacity a message is using. |
| **Container** | The platform box: Reel, TikTok, Short, long video, Story, post. |
| **Content pillar** | A repeating theme you can make many videos about. |
| **Content tree / idea tree** | One trunk topic with branches that can each become a video. |
| **Content type** | What the video is doing: vlog, explainer, come-with-me, and so on. |
| **Curiosity gap** | A hook that makes a specific unknown felt, then fills it. |
| **Engaged view** | A YouTube metric for views where someone stayed past the first seconds. Official definition first. |
| **Format** | In this guide, three layers: container, production format, content type. |
| **Framework** | A reusable sequence for a script. |
| **Hashtag** | A #word that can group or find posts. |
| **Hook** | The opening that earns the next seconds. |
| **House rule** | A rule of this guide, not an official platform standard. |
| **Impression** | A thumbnail or post was shown. |
| **Long-form** | A YouTube video that is not a Short. |
| **Maya Sen** | The fictional beginner used as a worked example. Not a real person. |
| **Modality / redundancy principles** | Multimedia-learning findings about spoken words, on-screen text and pictures. See chapter 6. |
| **Niche** | Your lane: who it is for, and what it is about. |
| **Open loop** | A question or thread you have started and not yet closed. |
| **PAS** | Problem–Agitate–Solve. Inventor unverified. Taught here without a product pitch. |
| **Payoff** | Where the opening promise is kept. |
| **Peak-end rule** | People often remember an experience by its peak and its ending. |
| **People Also Ask** | Related questions Google may show after a search. |
| **Platform** | The app: TikTok, Instagram, YouTube, X, and in shorter chapters LinkedIn and Threads. |
| **Production format** | How the pictures and sound are made (compilation, talking head, green screen…). |
| **Promise** | What the viewer can expect, from a video or from you. |
| **Ranking** | Ordering a pool of posts, often by predicted actions. |
| **Reach** | How many unique accounts or people saw the content, as officially defined. |
| **Recommendation system / “the algorithm”** | Software that predicts what a person might want to see next. |
| **Retention (platform)** | How much of the video people watched, as a official curve or average. |
| **Retention (memory)** | What people remember later. Not the same thing. |
| **Reel** | Instagram’s short vertical video container. |
| **Safe area** | The part of the frame not covered by buttons or interface. |
| **Short** | YouTube’s short vertical video container. |
| **Signal** | Something a recommender can observe (a watch, a skip, a share). |
| **Story Circle** | Dan Harmon’s eight-step story shape. |
| **Story Spine** | Kenn Adams’s sentence-level story tool. |
| **Surface** | Where a recommendation appears (For You, Home, Search…). |
| **Thumbnail** | The still shown before a YouTube video (and some other surfaces) plays. |
| **Topic cluster** | A web-content idea (pillar plus related pieces) we adapt as a tree of videos. |
| **Trial Reels** | Instagram’s official way to show a Reel to non-followers first, if you are eligible. |
| **Umbrella** | A niche wide enough to hold more than one interest for the same viewer. |
| **Vanity metric** | A number that is easy to look at and easy to over-read if used alone. |
| **View** | A platform-defined count of a view. Definitions differ, and YouTube has used co-view adjustments. |
| **Voice** | How you sound: wording, pace, what you will not pretend. |
| **Voiceover** | Speech recorded over pictures. |
| **Zeigarnik effect** | A 1927 claim that unfinished tasks are remembered better; a 2025 meta-analysis did not find a reliable memory advantage. |

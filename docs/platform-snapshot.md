# Platform snapshot

**Date of this snapshot: 20 November 2026 (Europe/London).**

This file is the easy place to refresh facts that move: button names, length limits, eligibility, hashtag caps, and official metric names. **Refresh it quarterly**, by the maintainer, and add a line to [CHANGELOG.md](https://github.com/brenotreviso/content-practice/blob/main/CHANGELOG.md). Do not silently edit history; add a new dated section at the top if you are keeping old snapshots, or update this page and note the date.

Nothing here is monetisation advice.

## How to refresh (for the maintainer)

1. Re-open every official URL in the table below.
2. Update any number, name or eligibility rule that has changed.
3. Re-check Instagram Trial Reels Help, Instagram hashtag Help, YouTube hashtag Help, YouTube analytics metric names (especially co-views, which Help said would be available until May 2027), and TikTok / Studio / Research UIs.
4. Look at the “social aspect” box in [chapter 10](10-platforms.md) and rewrite anything that is now out of date.
5. Mark anything you could not open as unverified.
6. Log the date and a one-line summary in the changelog.

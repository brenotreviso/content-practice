# Analytics review

Official numbers only, used as clues for one decision. See [chapter 11](../docs/11-analytics.md) and [checklists/review-48h.md](../checklists/review-48h.md). 48 hours is a house rule for a first look, not a platform law.

Put your month-one goal at the top. None of its bullets should be a view or follower target.

## Maya’s first Reel (teaching example)

Maya is fictional. These numbers are a teaching sketch, not real insights.

**Month-one goal:** four videos, one platform (Instagram), a written review each time, no deleting.

| Prompt | Maya’s note |
|---|---|
| Date posted / date reviewed | Friday post, reviewed Sunday morning |
| Platform and official tool | Instagram Insights |
| Promise of the post (written before looking) | A Tuesday dinner from one pan and a tin of tomatoes, no fourteen-ingredient recipe |
| Impressions / how many accounts were shown it | Small — few strangers saw it |
| Plays / views (official name) | A smaller number opened it |
| Did people stay? (retention, average percentage viewed, or “most who opened it stayed”) | Of the people who opened it, most stayed to the end |
| Response (comments, saves, shares — official only) | One comment asked about the onions |
| Useful conclusion | The promise worked for the people who saw it |
| One next experiment | A clearer first frame — not “I should quit” |
| Comparison I will not make | A cooking account with 200,000 followers |
| Did I delete the post? | No |
